CustomLang Grammar Specification
================================

1. LEXICAL ELEMENTS

1.1 Identifiers
   Pattern: [A-Z][a-z0-9_]{0,30}
   Description: Start with uppercase letter, followed by lowercase letters, digits, or underscores
   Maximum Length: 31 characters

1.2 Integer Literals
   Pattern: [+-]?[0-9]+
   Description: Optional sign followed by one or more digits

1.3 Floating-Point Literals
   Pattern: [+-]?[0-9]+\.[0-9]{1,6}([eE][+-]?[0-9]+)?
   Description: Optional sign, digits, decimal point, 1-6 decimal digits, optional exponent

1.4 Boolean Literals
   Pattern: (true|false)
   Description: Case-sensitive boolean values

1.5 Punctuators
   Pattern: [(){}[\],;:]
   Tokens: ( ) { } [ ] , ; :

1.6 Comments
   Single-line: ##[^\n]*
   Description: Hash-hash followed by any characters until newline

1.7 Whitespace
   Pattern: [ \t\r\n]+
   Description: Spaces, tabs, carriage returns, newlines (skipped but tracked for line numbers)


2. TOKEN PRIORITY (for pattern matching)

   Priority Order:
   1. Single-line comments
   2. Boolean literals
   3. Identifiers
   4. Floating-point literals
   5. Integer literals
   6. Punctuators
   7. Whitespace


3. LEXICAL RULES

   - Longest match principle applies
   - Case-sensitive matching
   - Line and column tracking required
   - Error recovery: skip invalid characters and continue


4. ERROR CONDITIONS

   4.1 Invalid Characters
       - Characters not in alphabet: @, $, %, etc.
   
   4.2 Malformed Literals
       - Multiple decimal points
       - Invalid exponent format
       - Too many decimal places (>6)
   
   4.3 Invalid Identifiers
       - Starting with lowercase, digit, or underscore
       - Exceeding 31 characters
   
   4.4 Unclosed Comments
       - Multi-line comments not closed (if applicable)


5. SYMBOL TABLE ENTRIES

   For each identifier, store:
   - Name
   - Type
   - First occurrence (line, column)
   - Frequency of occurrence


6. OUTPUT FORMAT

   Token Format: <TokenType, "lexeme", Line: X, Col: Y>
   
   Example:
   <IDENTIFIER, "Count", Line: 1, Col: 1>
   <INTEGER_LITERAL, "42", Line: 1, Col: 9>
   <SEMICOLON, ";", Line: 1, Col: 11>
